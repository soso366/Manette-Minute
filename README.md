# Manette Minute – appli Fire TV

Appli de borne : écran d'accueil « Prêt à jouer ? », lancement automatique du jeu payé
(GeForce NOW, Amazon Luna…), fermeture à la fin du temps, verrouillage de la borne.

L'APK est fabriqué automatiquement par GitHub à chaque modification :
onglet **Releases** → `ManetteMinute.apk`.
